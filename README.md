# Birthmark

Offline, single-device app for recording timed moments during a birth. One tap records the time; labels are optional and can come later. Supports overlapping event timers, review with corrections that never erase the original capture, untimed APGAR scores, and a locally generated PDF report.

Spec: [docs/Birthmark_MVP.md](docs/Birthmark_MVP.md). Acceptance status: [docs/acceptance-status.md](docs/acceptance-status.md).

## Requirements

- Node.js LTS, npm
- Android Studio (SDK + emulator, JDK 17+) and/or Xcode with an iOS simulator
- A development build. Expo Go cannot load the local `ClockSnapshot` native module; the app then falls back to a JS clock that does not track device sleep and says so on the home screen.

## Develop

```bash
npm install
npm run android          # expo run:android - builds the dev client and installs it
npm run ios              # expo run:ios
npm start                # expo start --dev-client, for an already installed dev client
```

`ios/` and `android/` are generated by `npx expo prebuild` and are gitignored. Configure native behavior in `app.json`.

iOS 27 SDK builds (Xcode 27) are killed at launch unless the app uses the UIScene life cycle. On Expo SDK 57 this comes from `expo-build-properties` with `ios.enableSceneSupport: true` in `app.json` (it needs `expo` >= 57.0.23). After changing it, run `npx expo prebuild --platform ios --clean`. On SDK 58 and later, the template has scene support and the flag can be removed. See [expo/fyi: ios-scene-lifecycle](https://github.com/expo/fyi/blob/main/ios-scene-lifecycle.md).

### Emergency button in development

Development builds never place a call: the Emergency button shows `Demo - no call placed`. Release builds hand off `tel:911` to the system phone app.

- `EXPO_PUBLIC_PHONE_MODE=live` enables the real handoff in a development build.
- `EXPO_PUBLIC_TEST_CALL_NUMBER=<non-emergency number>` dials that number instead and labels the screen `TEST BUILD`. Never validate with a real 911 call.

## Layout

| Path | Role |
| --- | --- |
| `src/app/` | Routes: home/history (`index`), recording (`record`), report (`report/[id]`) |
| `src/components/` | Clock, milestone row, live status, capture bar, events drawer, APGAR, emergency, correction sheets |
| `src/domain/` | Types, time rules, timeline derivations, manual time entry, session controller, emergency handoff |
| `src/storage/` | SQLite schema/migrations, repository, serialized write queue |
| `src/report/` | Report model and escaped HTML renderer |
| `src/platform/` | Native clock, database, phone, PDF export adapters |
| `modules/clock-snapshot/` | Local Expo module: Swift `mach_continuous_time`, Kotlin `elapsedRealtime` |
| `tests/` | Jest suites named after spec scenario IDs |
